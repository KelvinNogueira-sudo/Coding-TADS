# Email_Creator:

  Crie um código que gere e-mails automáticos no formato: PrimeiroNome.ÚltimoNome@ufrn.edu.br                                                                                                              
  Exemplo:                                                                                                                                                                                                    
    Entrada: Pedro Alvares Cabral                                                                                                                                                                             
    Saída: pedro.cabral@ufrn.edu.br

  Obs:                                                                                                                                                                                                        
    1- Os nomes podem ser digitados de qualquer forma, maiúsculo, minúsculo, misto;                                                                                                                           
    2- Assuma que no nome sempre haverá duas partes no mínimo;                                                                                                                                                
    3- Acentos no nome podem ser considerados na saída (embora não existam e-mails com acentos.
